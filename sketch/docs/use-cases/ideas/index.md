# Ideas

An Idea is the entry point into the workflow — a raw problem statement, feature request, or opportunity that has not yet been structured.

## Use Cases

### Start from an Idea

As a software engineer, I want to capture an Idea in order to begin [Gathering Requirements](../requirements-gathering/index.md) and initiate the software development workflow.

> [!NOTE]
> An Idea does not need to be well-formed. The requirements gathering phase exists to structure it. Proceed to [Requirements Gathering](../requirements-gathering/index.md) as soon as you have a problem worth exploring.

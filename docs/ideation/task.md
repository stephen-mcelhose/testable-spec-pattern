# Task

## Overview

Explore and build a pattern/workflow/discipline around a testable behavioral spec pattern for Go.

## Goals

- Explore and build a workflow around a testable behavioral spec pattern for Go.
- Document the discipline/workflow.
- Build a set of agentic skills for the workflow.
- Create examples, human, automated, and mixed using the workflow in examples
- Iterate relentlessly on the workflow and skills.
- Learn and grow as a developer.

## Non-Goals

- Sharing the skills with the community. This is a workflow for me, it will be freely available, but I won't push it.


## Assumptions

- Runnable specs are useful.
- Runnable specs will help facilitate well organized codebases.
- I will have opinionated view of what disciplineswill help make testable specs viable.

## Risks

- One point of view.
- I'm m only "customer" of the workflow.

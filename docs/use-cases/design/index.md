# Design

The design phase produces structural decisions about *how* to build — informed by [Requirements](../requirements-gathering/requirements.md) and [Contracts](../contracts-and-domain-modeling/contracts.md), before implementation begins.

## Use Cases

- Design a new feature from [Requirements](../requirements-gathering/requirements.md)
- Design a new feature from [Requirements](../requirements-gathering/requirements.md) and [Contracts](../contracts-and-domain-modeling/contracts.md)

> [!NOTE]
> Design is distinct from domain modeling. Domain modeling names the things; design decides how they are arranged and connected.
